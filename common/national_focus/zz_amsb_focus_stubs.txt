# AMSB: hidden stub definitions for vanilla focus ids that no longer exist after the MSB tree rework.
# Loading vanilla content (minor-country trees, events, decisions, MIOs, autonomy states, raids,
# operations, scripted loc, ai_strategy) still references these ids via has_completed_focus,
# focus_progress, and complete/uncomplete_national_focus; a reference to a missing focus is a
# null-pointer CTD the moment it evaluates with a live scope (engine RVA hoi4+0x4a4f26 - the
# not-found sentinel indexes one past the focus DB; see 2026-06-12 crash forensics).
# focus_progress and effect references are NEVER validation-logged - sweep them explicitly
# (tools: the sweep scripts from the 06-12 session) instead of trusting error.log.
# Defining every id makes all references resolve; has_completed_focus on a stub is always false
# and focus_progress is always 0, which is the correct semantics: these vanilla branches can
# never happen in this mod.
# IMPORTANT: every id here MUST be checked against the effective load set (mod files + vanilla
# files not shadowed by a same-name mod file) before being added. A stub that duplicates a real
# focus id silently REPLACES it and the focus vanishes from its tree in game (2026-06-13:
# 57 Romania ids + others were wrongly stubbed and gutted the Romania tree).
# The tree is never assigned to any country (factor 0) and every focus is allow_branch = no,
# so nothing here is ever visible or selectable in game.
